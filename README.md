# 🎓 EDUCATION-AI — Dynamic Study Planner MVP

EDUCATION-AI is an intelligent, personalized study schedule generator built for students. Powered by Google's Gemini API and Streamlit, it turns complex course topics and tight deadlines into structured, actionable day-by-day study roadmaps.

---

## ✨ Features

- **Personalized Schedules:** Generates daily study plans based on subject topics and available preparation days.
- **AI-Driven Insights:** Powered by Gemini for dynamic topic breakdown and time management tips.
- **Simple UI:** Interactive, fast, and easy-to-use interface built with Streamlit.

---

## 🚀 Tech Stack

- **Frontend / Framework:** [Streamlit](https://streamlit.io/)
- **AI Model:** Google Gemini API (`google-genai`)
- **Language:** Python 3.10+
